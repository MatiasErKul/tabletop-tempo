# Music and charts

All music in Tabletop Tempo is **original** and generated by `tools/music/ttmusic.py`
(Python standard library only, no downloads). No commercial recordings, song names or artist
names are used anywhere.

## How it works

Each stage has one pattern file in `tools/music/patterns/<id>.json`:

- `sections`: bars, optional `bpm` (tempo can step up between sections: slow → full tempo),
  drum / bass / melody pattern names, `chart` pattern name, `phase` and a short `coach` line.
- `drumPatterns`, `bassPatterns`, `melodyPatterns`: 16 steps per 4/4 bar
  (`x` hit, `X` accent, `.` rest, `-` sustain for bass).
- `chartPatterns`: which move happens on which step, e.g. `{"steps": "x...x...x...x...", "move": "CLAP"}`.

One command renders both outputs from the same data, so they can never drift apart:

```bash
python tools/music/ttmusic.py all
```

| Output | Path |
|---|---|
| Backing track (44.1 kHz, 16-bit stereo WAV, Git LFS) | `TabletopTempo/Assets/_Project/Audio/Music/<id>.wav` |
| Starter chart (JSON) | `TabletopTempo/Assets/StreamingAssets/Charts/<id>.json` |

Chart format (read by the game's chart loader):

```json
{
  "id": "stage1_first_claps", "title": "First Claps", "audio": "Music/stage1_first_claps",
  "offsetSeconds": 0.1, "beatsPerBar": 4,
  "tempo": [{"beat": 0, "bpm": 72}, {"beat": 20, "bpm": 80}],
  "lengthBeats": 60,
  "sections": [{"name": "quarters_slow", "startBeat": 4, "bars": 4, "bpm": 72, "phase": "play", "coach": "Clap on every beat"}],
  "notes": [{"beat": 4.0, "move": "CLAP", "hand": "both"}]
}
```

`offsetSeconds` is the audio time of beat 0. `tempo` is a piecewise-constant tempo map.

## Replacing a track with your own (or a verified CC0 recording)

1. Check the license. Only your own work, CC0 or public domain. Record it in `THIRD_PARTY_NOTICES.md`.
2. Export a WAV and put it at `TabletopTempo/Assets/_Project/Audio/Music/<id>.wav` (same name).
3. Edit `TabletopTempo/Assets/StreamingAssets/Charts/<id>.json`:
   - `offsetSeconds` = time (s) of the first downbeat in your file,
   - `tempo` = your track's tempo (one entry if it never changes),
   - move `notes` so they sit on your track's beats.
4. Don't re-run `ttmusic.py` for that id afterwards, or it will overwrite both files
   (or rename the pattern file to keep it as a reference).
